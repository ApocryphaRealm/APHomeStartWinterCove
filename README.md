# AP Home Start - Winter Cove

One of the AP Home Start series, an add-on for [Alternate Perspective](https://www.nexusmods.com/skyrimspecialedition/mods/50307) and
[Winter Cove](https://www.nexusmods.com/skyrimspecialedition/mods/4171): start the game inside the home, already yours, from AP's
"My own home" card. See `dist/README.txt`.

Version 2.0.0
